# Portfolio — Baxtiyorov Shohjahon

Modern, responsive portfolio built with **React + Vite**.

## Run locally

```bash
cd portfolio
npm install
npm run dev
```

Then open the URL shown in the terminal (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```

## Customize content (easy updates)

Edit:
- `src/content.js` — your name, email, links, projects, and skills

## Deploy options

### Netlify (recommended)
- Build command: `npm run build`
- Publish directory: `dist`

### GitHub Pages
If you want GitHub Pages, the simplest path is to deploy from a CI workflow that uploads the `dist` folder.
If you tell me your GitHub repo name, I can add a ready-to-use GitHub Actions workflow.
